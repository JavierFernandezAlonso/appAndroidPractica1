# STUDYPLAN

### Aplicación Android para la organización de estudios

---

## 1. Introducción

StudyPlan es una aplicación móvil orientada a ayudar al alumnado a organizar sus estudios desde una interfaz sencilla e intuitiva.

Reúne en un mismo lugar diferentes herramientas para facilitar la planificación académica, como el acceso a asignaturas, tareas, horario de clases y una calculadora de notas.

## 2. Objetivos

El objetivo principal es desarrollar una aplicación funcional y fácil de utilizar, aplicando los conocimientos adquiridos en la asignatura de desarrollo de aplicaciones Android.

A través de este proyecto se pretende practicar:

- La creación y diseño de interfaces.
- La navegación entre diferentes Activities.
- La recogida y gestión de datos mediante formularios.
- La interacción con botones y otros componentes.
- La comunicación entre pantallas mediante Intent.

## 3. Tecnologías y alcance

El proyecto se desarrolla utilizando las siguientes tecnologías:

- **Android Studio:** entorno de desarrollo.
- **Java:** lenguaje utilizado para implementar la lógica de la aplicación.
- **XML:** diseño y configuración de las interfaces.

Se prioriza la utilización de los componentes y recursos trabajados en clase, como `TextView`, `EditText`, `Button`, eventos `onClick` e `Intent`.

El proyecto mantiene un enfoque práctico y académico, sin plantear la incorporación de bases de datos, `RecyclerView` ni calendarios avanzados.
